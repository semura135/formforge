# FormForge

FormForge is a visual form builder built with React.

It allows users to create and customize forms, preview them as a finished form, validate responses, and automatically save the form structure locally.

## Features

- Add text, email, number, textarea, select, and checkbox fields
- Edit field labels and placeholders
- Mark fields as required
- Delete fields
- Reorder fields
- Edit form title and description
- Preview the finished form
- Controlled form inputs
- Required-field validation
- Form submission handling
- Save and restore forms with localStorage
- Responsive interface

## Tech Stack

- React
- JavaScript
- Vite
- CSS
- Browser localStorage

## Getting Started

Clone the repository and install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown by Vite.

## Project Purpose

FormForge was built as a practical React project to apply component-based architecture, props, callbacks, state management, useReducer, controlled inputs, form validation, persistence, and conditional rendering in a real application.
